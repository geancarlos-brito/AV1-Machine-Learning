## 🎵 Problema 4 — Clusterização Musical

O objetivo é agrupar músicas com base em suas características acústicas, buscando identificar grupos que possam representar playlists com características semelhantes.

Nesta etapa, são explorados:

- Limpeza e preparação dos dados;
- Análise da correlação entre energia (*energy*) e acústica (*acousticness*);
- Pré-processamento de variáveis numéricas e categóricas;
- Aplicação do algoritmo K-Means com cinco clusters;
- Análise dos grupos e interpretação das músicas agrupadas.

O gênero musical cadastrado não é utilizado como variável de entrada do modelo.
